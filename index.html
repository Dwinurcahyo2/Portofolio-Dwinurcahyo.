Tentang Saya

Halo, perkenalkan, saya Dwi Nur Cahyo, lulusan Teknik Informatika dari Universitas Mercu Buana. Saya tertarik pada dunia teknologi, khususnya pengembangan website dan IT support. Saya berkomitmen menciptakan pengalaman digital yang tidak hanya menarik secara visual, tetapi juga fungsional dan responsif. Selama masa studi, saya terus mengasah kemampuan teknis dan memiliki pengalaman menggunakan PHP, JavaScript, HTML, dan CSS, serta dapat menggunakan Figma untuk merancang prototipe.

Spesialis & Tech Stack

Sebagai Full Stack Web Developer, spesialisasi saya ada pada pengembangan sistem menggunakan PHP dengan framework Laravel. Keahlian utama saya meliputi:
Backend: PHP (Laravel), RESTful API Development.
Database: MySQL, PosgreSQL
Frontend Dasar: HTML, CSS, JavaScript (termasuk utility-first framework seperti Tailwind CSS, Bootstrap).

Sistem Booking Lapangan Futsal

Pembangunan

Sistem Manajemen Barbershop

Pembangunan

Sistem Manajemen Barbershop adalah sebuah platform yang dirancang untuk membantu pemilik barbershop dalam mengelola operasional bisnis mereka secara efisien. Sistem ini mencakup fitur-fitur seperti manajemen pelanggan member, pengelolaan absensi, gaji karyawan, jadwal cuti dan pelaporan keuangan, sehingga pemilik dapat fokus pada pelayanan pelanggan dan pertumbuhan bisnis.
